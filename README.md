# DL4S-Tensorboard

A pure Swift summary writer for [DL4S](https://github.com/palle-k/DL4S) that writes TensorBoard log files.

### Requirements

- Swift 6.2 or later.
- macOS 15 or later, or Linux.
- [libgd](https://libgd.github.io), which [SwiftGD](https://github.com/twostraws/SwiftGD) uses to encode images. `brew install gd` / `apt install libgd-dev`

### Installation

Add DL4S-Tensorboard as a package dependency in `Package.swift`.

    .package(url: "https://github.com/palle-k/DL4S.git", branch: "master"),
    .package(url: "https://github.com/palle-k/DL4S-Tensorboard.git", branch: "master"),

Then add `DL4STensorboard` as a target dependency:

    .target(
        name: "YourAwesomeTarget",
        dependencies: [
            .product(name: "DL4S", package: "DL4S"),
            .product(name: "DL4STensorboard", package: "DL4S-Tensorboard"),
        ]
    ),

### Usage

DL4S-Tensorboard supports scalars, images, text, tensors, embeddings, and histograms.

#### Writing scalars

```swift
import DL4STensorboard
import Foundation

let logdir = URL(fileURLWithPath: "./logs")

let writer = try TensorboardWriter(logDirectory: logdir, runName: "Classifier")

try writer.write(scalar: 101, withTag: "model/accuracy", atStep: 1337)
```

#### Advanced Usage

```swift
// writing an image with shape [height, width] or [channels, height, width]
try writer.write(image: imageTensor, withTag: "generator/output", atStep: 42)

// writing text
try writer.write(text: "Lorem ipsum dolor sit amet", withTag: "lm/sample", atStep: 314)

// writing a tensor
try writer.write(tensor: logits, withTag: "model/logits", atStep: 42)

// writing embeddings
let embeddingLayer = DL4S.Embedding<Float, CPU>(inputFeatures: 42, outputSize: 128)
try writer.write(embedding: embeddingLayer.embeddingMatrix, withLabels: vocab, atStep: 1337)

// writing a histogram
let histogram = Histogram(values: valueDistribution, buckets: 10)
try writer.write(histogram: histogram, withTag: "data/histogram", atStep: 4242)
```

### Development

The files in `Sources/DL4STensorboard/Autogenerated` are generated from TensorFlow proto definitions. To regenerate them, make sure `protoc` and `protoc-gen-swift` are installed and run `util/generate-protos.sh`.

```
nix-shell -p protobuf protoc-gen-swift --run util/generate-protos.sh
```
